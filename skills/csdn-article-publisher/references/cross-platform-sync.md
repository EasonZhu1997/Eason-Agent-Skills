# 从 CSDN 同步到掘金与知乎

仅在用户本次明确要求跨平台时读取并执行。本文件讲“一稿多投”的工作流，不是持续监听、双向同步或 CSDN 私有发布 API。

## 官方能力与前提

CSDN 官方手册列出掘金、知乎同步支持：使用「CSDN 同步助手」浏览器扩展，在同一浏览器登录目标站点；从创作中心的内容管理或多平台发布入口选择目标。同步完成后进入目标草稿，检查后再正式发布。参见 [官方操作手册](https://blog.csdn.net/blogdevteam/article/details/159927751) 和 [官方助手入口](https://sync.csdn.net/)。

资料核对日期：2026-09-06；手册首次发布于 2026-04-08，更新于 2026-08-21。页面名称、支持范围和账号条件仍以使用时实际界面为准。以上是公开说明核实，不证明当前用户的浏览器已安装扩展或同步实测已通过；不承诺免费、排版无损或绝对安全。本包只链接原文，不收录官方截图、扩展程序或完整手册。

## 先确认范围

- 记录源稿/已有 CSDN 文章、版本、目标账号、指定目标平台以及“草稿”或“正式发布”。没有指定目标时不默认勾选全部平台。
- 只发 CSDN，不启动其他平台；只要求同步，默认停在目标草稿；只有明确要求目标平台正式发布时才继续。
- 用户只要草稿而当前同步入口要求公开 CSDN 原文时，不为获得入口擅自发布原文。说明限制，使用现有可用的草稿入口或下文分平台草稿路线。
- 已有掘金或知乎文章时，先核对是否支持更新指定目标；不能把“再同步一次”当成一定会更新原帖。用户指定更新就保持原帖身份，保留其线上手动修改。

## 优先路线：官方同步助手

### 1. 只读检查本机条件

观察当前浏览器和正确账号的 CSDN 创作中心：寻找实际存在的同步入口、扩展状态以及目标平台登录提示。官方资料介绍 Chrome、Edge 等支持扩展的浏览器；不能假定应用内置浏览器也能加载扩展。Chrome 已登录也不表示另一个浏览器或另一份用户配置已登录。

不要为“验证”自动安装扩展、开开发者模式、绑定新权限或读取导出 Cookie。缺扩展或遇到新增访问权限时，说明需要用户安装/授权的事项，遵守宿主确认要求；只检查能力不等于授权安装或同步真实文章。官方助手自行利用浏览器登录态，不代表代理可以读取或复制凭据。

用户指定的浏览器无法使用助手时，先说明限制；本次请求未限定官方助手且仍有可靠原生编辑能力时，可保持该浏览器按下文分平台路线继续。确需换到受支持浏览器时再取得对应指示，不静默切换账号/浏览器。

### 2. 核对原文再选择目标

完成本技能的 CSDN 正文、图片位置和保存检查。确认同步使用的是用户指定且已保存的版本，不把尚未保存的编辑当作同步源。

按当前界面进入内容管理中对应文章的「同步多平台」，或多平台发布页面。核对选中文章标题、作者及目标账号，只选择用户要求的掘金和/或知乎。按钮名称只是定位线索，不使用旧坐标、猜测 URL、隐藏编辑器对象或私有接口。

### 3. 同步并保留逐平台记录

已有明确同步授权且本机条件满足时，执行界面中的同步动作。它会向目标站点传输正文和图片，即使只生成草稿也属于外部写入。

若当前界面提示该动作会直接公开内容，不能依赖历史手册将它视为“仅存草稿”；按本次用户授权核对，草稿任务停在该动作前。

在当前页面或同步历史查看每个目标的实际状态；从真实结果入口打开目标草稿，记录实际链接。不要只凭总进度、成功弹窗或 CSDN 已公开就宣布三个平台全部完成。

### 4. 在目标草稿验收

- **掘金**：核对正文 Markdown 的实际预览、标题层级、代码空格/换行、列表、链接、图注和配图位置；分类、标签和封面按本次稿件选择。
- **知乎**：核对进入的是文章编辑器而非问题回答或想法；重点看富文本标题、代码块、表格、超链接与图片邻接关系，别把 Markdown 源码留在正文。
- 同步工具可能已转存图片，不因进入新平台就一律再上传。先检查真实加载结果、来源与原图对应；缺图或防盗链失败时才用目标平台原生传图修复。
- 不能靠放宽本地脚本图床白名单“证明”同步正确，也不能把 CSDN 图片地址冒充已由掘金/知乎上传。保留正文原位置，逐个核对重复用图。
- 纯 TXT 的缩进、连续空格和首尾空行需在每个目标重新检查；源稿保真不保证跨平台转换仍保真。

只同步草稿的任务到此停止。用户明确要求正式发布时，核对各平台必要字段、真实创作声明和正文后，分别按该平台界面完成发布，再记录审核与公开状态。不勾选无关营销、奖励或付费权益。

## 失败恢复与分平台备选

先查同步历史及目标草稿/文章：成功项不重跑，失败项确认没有生成内容后再按原因处理。超时或状态未知时不要立即切到手动新建，可能造成重复文章。不能确定是否已建稿时，停在该平台核实；其他已成功平台不删除、不回滚。

官方路线不可用，而用户未限定只能使用该助手时，可说明改用分平台方式，在原本授权的目标、浏览器和草稿/公开范围内继续，不重复索要同一发布授权。需要换浏览器、装新工具或扩大权限时再取得对应指示。复用同一份经确认的源稿和本地图，在各平台单独准备、上传、校对。**复用的是原文与素材，不是平台托管地址、准备清单或发布状态。**

- 当前会话确实可用 `juejin-article-publisher` / `zhihu-article-publisher` 时，先读取对应技能和本次所需参考，再执行该平台流程；这两个是可选能力，不是 CSDN 包内隐含的文件依赖。
- 不可用时，不编造技能路径或调用不存在的脚本。仍可按本文件通过已验证的官方同步路线工作；若官方路线也不可用，则交付已完成部分，说明需目标技能或可可靠操作的原生编辑能力。
- 手动图片路线分别生成 `CS_IMAGE`、`JJ_IMAGE`、`ZH_IMAGE` 清单及各自图床映射。不把 CSDN 最终稿直接当作另一个平台的“已上传图片原稿”；从共同的本地源稿重新准备。
- 每个平台有独立工作目录、草稿/文章链接及状态。离线准备可并行；浏览器写入要保证每个编辑器只有一个操作者，不能多个代理争用同一标签、焦点或剪贴板。

## 完成记录

工作目录中逐平台记录：源版本、操作方式（官方同步/独立流程）、新建或更新、账号核对结果、实际草稿或文章链接、图片与格式验收、当前状态、阻断项和下一步。记录不要打进技能包；敏感 URL 或账号资料不公开。

区分：待同步 → 目标草稿已生成 → 草稿已检查 → 已提交发布/审核中 → 公开页已验证。部分成功就逐项报告，不用一个“同步完成”抹平差异。同步后编辑 CSDN 原文不会在本技能中自动触发其他平台更新。

## 本机验证边界

只验证技能时，使用合成稿做离线测试及路由演练，或只读检查当前入口、扩展、登录提示。真实同步、创建目标草稿、安装扩展和正式发帖各自需要对应授权，不能用“测试”默认获得。

建议演练四种情况：只发 CSDN；同步两站但不公开；一站成功、一站状态未知；指定浏览器不支持扩展。验证每种情况的目标范围、所需权限、恢复策略和停止位置。未执行线上同步时，只报告本地测试/官方资料核对结果。
