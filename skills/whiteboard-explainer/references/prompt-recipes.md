# 白板布局与提示词模板

选择与内容相符的模板；花括号由实际材料替换，不原样进入成图。默认 16:9、单页一问、总—分—结，用户指定的比例、形式、准确文字和修改范围优先。

## 通用骨架

```text
制作一张中文白板手绘讲解图，主题“{主题}”，让{读者}看完能够{学习结果}。
采用{比例，默认 16:9}，正面平视近白可擦白板，平整表面，极轻擦拭痕迹，无大反光。
用深黑或深蓝马克笔写清楚的中文，连续圆头或扁头线条，轻微叠色和自然墨迹浓淡差异。
蓝色表示分区、边框和结构箭头；黄色仅作少量半透明衬底，衬底上的字仍为深黑或深蓝。
不使用黄色文字，不用单独的黄色线条表示流程、连接或边界；关键关系不依赖黄色才能读懂。
红色只提示有依据的风险或错误；绿色只表示有依据的通过状态或带明确文字的条件分支。
未执行、待检查的事项用中性状态词；方法示例不能画成已经验证或已经完成。
不要纸纹、粉笔颗粒、黑板底色、遮字反光、教室背景、无关装饰、品牌 Logo 或水印。
这是一张独立完整单页，只回答一个核心问题；不拼成多页缩略图或多联海报。
顶部深色大标题和短副标题；中部为{位置、大小层级和阅读顺序}；底部一句深色结论。
准确上图文字：{标题、副标题、各区标题、节点说明、必要箭头标签、底部结论}。
关系：{逐条写清箭头起点、终点和含义；说明哪些内容仅并列而不相连}。
重点：{需铺半透明黄色衬底的少量词句}。图标：{相关通用简笔图标，可省略}。
每块通常一至三行，说明字在常见阅读尺寸下清楚可读；留足边距，线不穿字，不裁内容。
{如有参考图：仅参考板面、笔触与布局气质，不复制无关主题、品牌、角色、页码或状态。}
```

## A. 流程与检查回路

适合项目步骤、教学流程和阶段工作法。把动作顺序与检查条件写清楚；箭头回到需要修改的动作，不能只指向整个画面。以下为方法示意，不报告实际项目状态。

```text
画一张 16:9 中文白板讲解图，标题“先说清楚，再开始做”。
副标题“一个小项目的工作步骤示例”。采用近白可擦白板、深色马克笔字和蓝色结构线。
顶部提出问题：“怎样让每一步都有明确的交付？”
中间从左向右排列四个节点：
“1 规划｜写清目标、范围与检查条件”
“2 执行｜按约定完成这一轮工作”
“3 检查｜把结果与条件逐项对照”
“4 交付｜整理成果、说明与已知问题”。
蓝色箭头连接“规划 → 执行 → 检查”。
从“检查”到“交付”画箭头，旁边深绿色文字“符合条件时”；这是条件，不是已通过标记。
从“检查”沿下方画蓝色回退箭头到“执行”，标注“不符：返回修改”。
侧注：“检查条件可随任务调整；本图不表示任何阶段已执行。”
底部深色结论：“先约定交付和检查方式，再按结果决定下一步。”
在“交付和检查方式”背后铺浅黄色半透明衬底；不写黄字，不给节点加完成勾。
马克笔线条连续自然，不加纸纹、粉笔颗粒或大反光；保留清楚的空白和完整边缘。
```

## B. 概念或方案对比

适合分清两个概念或比较方案。选择同一组维度横向对齐；并列关系不用流程箭头，适用条件不同不等于一方错误。

```text
制作一张 16:9 白板讲解图，标题“规划和检查，各自解决什么问题？”
副标题“项目工作中的两种职责”。近白可擦白板，深黑马克笔正文，蓝色框线。
主体两栏，按“回答的问题 / 主要动作 / 形成的材料”逐行对齐：
左栏“规划｜做什么、边界在哪里？｜写清目标与条件｜目标、范围、检查条件”。
右栏“检查｜结果是否符合约定？｜对照条件记录结果｜检查记录、问题清单”。
两栏是概念对比，不连成固定时间线，不设置红绿优劣状态。
底部深色结论：“规划明确约定，检查对照结果。”在关键词背后铺半透明黄色。
配清单和记录本的少量深色简笔线稿；不加事实材料未提供的效率数字或完成状态。
```

## C. 分工或条件矩阵

矩阵用于在同一问题下比较角色、职责或条件组合；每行字段一致。主体网格是内容组织，不是多张小海报拼接。

```text
制作一张独立的 16:9 白板讲解图，标题“一个小项目，怎样分工？”
副标题“示例分工，同一个人可以承担多项职责”。
近白可擦白板，连续的深色马克笔字，蓝色表头与网格，轻微自然叠色，无大反光。
中间做三行矩阵，列名为“职责 / 负责什么 / 交付什么”：
“需求整理 / 写清目标和限制 / 检查条件”
“实现修改 / 按约定完成改动 / 可检查的版本”
“检查记录 / 对照条件检查 / 结果与问题记录”。
分工不代表互相排斥的人物身份，不用箭头把矩阵串成固定时间线。
底部深色结论：“先说清每项职责的交付，再约定交接方式。”
黄色仅半透明衬在“交付”和“交接方式”下方；本页没有实际验收结果，不用完成勾。
```

## D. 方法论与适用边界

适合解释一种方法为什么有用、何时采用、怎样落实。围绕同一核心命题组织“理由—条件—做法”，避免把多个独立主题挤成一页。

```text
制作一张 16:9 中文白板讲解图，标题“什么时候需要分阶段检查？”
副标题“按任务复杂度调整的方法示例”。近白板面，深色马克笔字，蓝色分区与结构线。
顶部“为什么”：“依赖较多时，中途对照条件有助于发现偏差。”
中部左右对照：“适合设置多个检查点｜依赖多、交付跨多个环节”；
“可以简化｜边界清楚、改动很小、一次检查足够”。
两侧均用蓝色结构与深色文字，不把“可以简化”画成风险或错误。
下部“怎样落实”：“明确本阶段交付 → 执行 → 对照条件检查”。
检查后以带文字的条件分支表示“符合：进入下一阶段”“不符：返回执行”。
底部深色结论：“检查点服务于任务，每个阶段都要有可检查的结果。”局部黄色半透明衬底。
本图仅介绍方法，不声称实际已验证，不把未执行阶段画成绿色完成，不编造收益比例。
```

## E. 多页讲解

一页文字过密时，按学习结果拆页，例如“认识问题”“掌握步骤”“理解分工”；页数由材料决定，每页仍有自己的问题、主体和结论。各页分别生成并保存，统一板面、马克笔笔触、文字层级和颜色含义。仅在真实系列中写实际页码；用户指定单页时优先精简内容，不擅自改成系列。

## 最短复用提示

```text
用白板马克笔手绘风格制作一张默认 16:9 的独立讲解图：正面近白可擦白板，深黑或深蓝连续马克笔字，蓝色结构线，黄色仅作半透明衬底且搭配深色文字。红色表示有依据的风险，绿色表示有依据的通过或文字明确的条件，未执行不画完成。无纸纹、粉笔颗粒、大反光。顶部提出一个问题，中部用短句和准确关系解释，底部一句话回答；用户指定形式优先。主题与准确文字使用下方材料。
```

## 定向修正

```text
编辑这张已有白板图，只将检查节点后的回退线改为：从“检查”指回“执行”，标签“不符：返回修改”。删除原先指向“交付”的“不符”分支，保留“符合条件时”到“交付”的分支。其余文字、结构、位置、比例和马克笔画风保持不变，完整保留画布边缘。
```

修正文案时写出原文、新文与所在区域；修正低对比颜色时明确将黄字改成深色字，并把黄色保留为半透明衬底。不要仅要求“更清楚”或“把流程画对”。
