# 白板组件库

按讲解内容选用组件，统一一页或一套图的笔触、文字层级与颜色含义。默认单页按标题、主体、结论组织；用户指定形式时随之调整。

## 板面与笔触

- 使用正面平视的近白可擦白板，表面平整，允许极轻的擦拭痕迹；不出现纸纹、粉笔颗粒或遮挡文字的大反光。
- 文字和线稿采用深黑或深蓝马克笔，线条连续，圆头或扁头笔触自然统一；允许轻微叠色和墨迹浓淡差异，不做干粉断裂纹理。
- 正文保持深色，蓝色组织结构；黄色只作少量半透明衬底，其上使用深色文字，不能用黄字或仅用黄线承担关系。
- 红色表示有依据的风险或错误；绿色用于有依据的通过状态，或配明确文字的条件分支。讲未来步骤时不画已完成勾。

## 可选组件

| 组件 | 默认构成 | 使用要点 |
| --- | --- | --- |
| 主标题 | 深黑或深蓝粗马克笔字、短副标题 | 一句话提出本页问题；需要强调时在关键词背后铺半透明黄色，文字仍为深色 |
| 分区标题 | 蓝色短标题、细分隔线或浅框 | 同级分区同样式；避免把长标题挤入窄标签 |
| 步骤编号 | 蓝色圆圈、深色数字、动词短句 | 只对有顺序的动作编号；并列分类用项目符号或对齐模块 |
| 内容框 | 蓝色手绘框、深色名称、一至三行说明 | 表示归组，同类框字段一致；保持白底，不为每个词单独画框 |
| 流程箭头 | 蓝色连续线、明确箭头、必要短标签 | 交代顺序、输入输出或因果；不穿字、不穿框，不把分工自动串成时间线 |
| 检查与回退 | 检查节点、带文字的条件分支、回退箭头 | “符合条件”可用绿色标签；“不符：返回修改”写明终点，不能暗示本次已通过 |
| 对比栏 | 两三列等宽区域、共同维度、深色说明 | 左右字段对齐；差异用文字说清，不把备选方案涂成错误状态 |
| 模块矩阵 | 行列标题、同一套字段、少量蓝色网格 | 展示分类、角色或条件组合；每格回答同一问题，空缺写“未提供”而非补造事实 |
| 简笔图标 | 深黑或深蓝线稿、少量蓝色细节 | 清单、工具、文档等对应内容；只作辅助，不能代替职责、动作或结果文字 |
| 边注 | 一句小号深色手写说明、可选指向线 | 补前提或例外，不重复标题；长注释移入正文或另页 |
| 总结条 | 蓝色分隔或外框、深色结论、局部黄色衬底 | 一句话回答本页问题；突出一两个关键词，不用低对比黄字 |
| 状态标记 | 明确状态词、可选图形符号 | 已通过须有依据；待执行用中性“待执行 / 待检查”，假设结果标明“示例” |
| 页码 | 最小号深色字、实际页次 | 只给真实系列加页码；多页分别成图，单张不写虚构总页数 |

## 组合与阅读检查

- 流程：问题标题 + 编号动作 + 检查分支 + 完成标准；分工矩阵与动作主线分开表达。
- 对比或矩阵：问题标题 + 相同维度的对齐内容 + 条件说明 + 差异结论；不强加时间箭头。
- 方法论：问题标题 + 为什么 + 适用条件 + 实施机制 + 核心原则；复杂内容拆成各自完整的单页。
- 成图后确认：先看懂问题，再找到阅读顺序，最后能复述结论；所有关键关系在去掉黄色衬底后仍清楚可辨。
