# Rokid 图文发布技能分享包

把 Word 或 HTML 文章发布到 Rokid 开发者论坛；也可给原帖补图、校正图片位置、恢复标题层级与代码块。它是一套让 AI 按步骤执行、检查和交付的工作说明，不是免登录上传程序，也不保证平台审核或活动奖励。

## 如何交给别人使用

1. 发送整个 ZIP，不要只发 `SKILL.md`。解压后应保留 `rokid-article-publisher` 文件夹及其子目录。
2. 接收者在自己的 Codex 中打开该文件夹，请 AI 先读 `SKILL.md`，检查需要的浏览器控制能力是否可用。
3. 如需常用安装，可将整个文件夹复制到个人目录的 `.agents/skills/` 下；仅用于某个项目时，复制到该项目的 `.agents/skills/` 下。若有同名技能，先备份并比较，不要直接覆盖。不要把目录重复套成两层同名文件夹。
4. Codex 通常会自动发现技能；未显示时重新打开 Codex。安装后可在提示中提及 `$rokid-article-publisher`。

本包只交付桌面文件，没有自动安装、登录或授予网站权限。宿主若没有可用的浏览器控制工具，请先按宿主说明配置；不要把登录密码发给分享包作者。

## 可直接复制的使用示例

> 使用 $rokid-article-publisher。把我提供的 Word 发布到 Rokid 开发者论坛，使用内部浏览器，我来登录。保留标题和正文，图片按 Word 的图注顺序放置，恢复章节标题、列表和代码块。板块由我指定。发布前检查图片、链接和可见范围，发布后刷新原帖验证。

> 使用 $rokid-article-publisher。修复我指定的 Rokid 原帖，只补图和调整排版，不新建帖子，不改标题和正文措辞。保留我在网页中做过的修改。若 Word 与原帖有差异，先标出来再处理。

> 使用 $rokid-article-publisher。先准备本地发布材料并校验，不要登录网站、上传或发布。

提供：源文件、目标网站或原帖链接、新发还是修改、是否现在发布、目标板块。账号登录、验证码、缺少的个人资料由使用者完成或明确提供。

## 包含什么

- `SKILL.md`：工作流程与适用边界。
- `references/`：Rokid 编辑器的实测兼容说明及检查方法。
- `scripts/`：Word 图片清单、HTML 图片映射等纯本地助手及合成测试。
- `agents/openai.yaml`：技能显示信息。

脚本不会联网、登录或点击发布，只需 Python 3.9+ 标准库；具体命令见技能正文。脚本输出是核对材料，不等于网页上传成功。

## 分享与隐私

本包不附带真实文章、原图、账号、密码、Cookie、验证码、帖子 ID 或用户上传地址。使用中产生的原帖备份、Word 图片、上传映射、联系方式和截图应留在使用者自己的任务目录，不要加入公开分享包。对方须使用自己的账号，并确认拥有文章和配图的发布权。

## 官方说明与兼容性

本包的安装与调用说明参考 [OpenAI 官方技能文档](https://developers.openai.com/codex/skills/)，核对日期：2026-09-05。官方建议更广泛的可安装分发使用插件；本包按需求提供可复制的独立技能目录，未注册插件商店。

Rokid 的图片粘贴和排版经验是特定编辑器版本的实测结果，不是永久接口约定。首次在新环境使用时，先用少量内容检查；网站界面变化后应重新核对。
