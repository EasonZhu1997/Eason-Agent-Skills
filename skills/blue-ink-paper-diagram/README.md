# 蓝墨纸绘

把已有事实、架构或流程绘成暖白纸张上的黑笔线稿、蓝墨手写标注与少量黄色强调。先保证关系与文字准确，再应用画风。

## 使用

让支持技能的 AI 助手读取同目录 [SKILL.md](SKILL.md)，并提供要表达的事实、节点和关系，例如：

```text
使用 $blue-ink-paper-diagram，把“准备原稿→上传图片→校对正文→发布→核验”画成蓝墨纸绘流程图。发布失败单独作为反馈分支，人物用现代人。
```

宿主需要有可用的图片生成工具。没有图片生成能力时，只能交付提示词，不能声称已出图。生成后逐项检查中文标签、箭头方向、分支与独立关系；复杂说明放在图外，不把纸面塞满小字。

- `agents/openai.yaml`：技能显示与调用说明。

本公开版本不附带原技能的历史参考图片，因为没有确认其再分发授权。没有参考图时可直接使用文字规范；使用者也可提供自己有权使用的参考图。参考只用于风格，不复制其中的无关人物、文字、地图或品牌内容。

生成图片不会自动修改文档、上传或发布；这些操作需有本次明确请求。技能说明适用随目录提供的 [MIT 许可](LICENSE)，使用图片生成服务与输入素材仍需遵守各自规则。
