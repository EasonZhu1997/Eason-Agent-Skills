# 粉笔板书画风与排版

## 风格定位与页面结构

完整名称为“黑板手绘方法论信息图”。核心是课堂讲解、方法拆解和清晰的信息结构，适合知识框架、流程、对比、经验总结与适用边界说明。默认不采用广告式大口号、写实产品展示或纯装饰海报的组织方式。

每页只有一个核心问题，采用“顶部主题 → 中部拆解 → 底部总结”的总—分—结结构。默认 16:9 横版、独立单页输出；系列按实际页数分别交付，不把多页压成九宫格或拼图。单页内用于分类的模块矩阵不属于多页拼版。用户指定的画幅与输出形式优先。

## 黑板与笔触

- 底色是接近炭黑的深灰黑板，可有轻微擦拭方向、粉笔灰和使用痕迹。背景要均匀、低对比，不出现可辨认的旧文字。
- 默认正面平视，内容铺在整块板面上。无需木框、教室布景、投影透视、霓虹光或立体阴影。
- 粉笔笔画略有断续、粗细变化和颗粒感；粗标题有自然填笔痕迹，细字仍清晰。不要让磨损破坏汉字结构。
- 框线、箭头和下划线有轻微手绘起伏，但起点、终点和所属区域明确。不要故意画歪整张图。

## 颜色的职责

| 颜色 | 默认用途 | 使用方式 |
| --- | --- | --- |
| 粉笔白 | 标题、正文、主轮廓 | 承担大部分阅读信息，与黑板保持高对比 |
| 粉笔蓝 | 分区、指向、概念区别 | 框线、编号或一两个重点词，避免大片蓝底 |
| 粉笔黄 | 核心结论、关键动作 | 短划线、涂抹标题底或少量高亮 |
| 粉笔红 | 风险、错误、关键提醒 | 局部警示、叉号或波浪线，避免通篇告警 |
| 粉笔绿（按需） | 通过、验收、完成 | 小范围状态词、对勾或明确标注的“通过”分支 |

白、黄、蓝是主轴，红、绿按需加入，粉笔颜色通常不超过四五种。不要为了凑满配色增加并不存在的风险或验收状态。绿色可以表示标明身份的假设示例或条件分支；待执行的真实任务用“待验收”，不能画成已通过。编号通常同色，不能因数字顺序随意改变颜色语义。

这套配色是默认风格，用户可指定其他颜色。颜色语义在同一套图内保持一致，并用文字或形状重复表达。黄色实心涂抹上可用黑字；细黄线仍放在白字下方，避免透过字面影响阅读。

## 文字层级与密度

- 主标题是最大的一层，通常居中，用粗白色粉笔字配黄色手绘下划线；短副标题限定范围。可以是问题、判断、方法名或观点，不强制问句或固定句型。
- 分区标题次之，节点名和核心结论突出，解释文字与边注再降一级，真实系列的页码最小。手写感不意味着所有字一样大。
- 作为横版起点，可把顶部约 15% 留给标题，中部约 60% 讲关系，底部约 25% 放结论；内容决定最终比例，结论短时应缩小底栏。
- 在 1600 × 900 附近的画布上，说明文字可从约 24–30 px 的视觉字号起步。缩小到一半宽度检查；手机阅读仍困难时减少内容或改竖版。
- 节点名尽量 4–14 个汉字，每块通常一至三行，解释优先压成一两行短句。单张常从约 200–350 字安排，字数包含副标题和边注；这只是压缩提示，不是硬性配额。
- 命令、公式和英文缩写需要更规整的字形。大小写、标点与路径保持原样，不为追求“手写味”牺牲准确性。
- 一段长材料可拆成“问题、方法、示例”三张，也可只保留最关键的一张。不要自动复制 `01 / 03`：只有实际系列交付才加对应页码。
- 文案像老师口头讲解，用具体动作与清楚的条件。首次出现影响理解的英文术语配简短中文解释；中英文混排自然，不照搬示例中的 Phase、Session 或 Agent。对比内容成立时才用对比表达，不为了金句夸大或制造二选一。

## 分区与阅读路径

- 先让人看见标题，然后能顺着明显的阅读方向读完主体，最后落在一句结论上。
- 可用横向框、丝带形小标题、括号式分组或圆角手绘卡片；每个区域只承担一种讲解角色。
- 横向主线避免超过约五六个大节点；超长流程改成分阶段或另起一页，转行时明确连续方向。
- 顺序箭头表示发生先后；因果箭头需要材料支持；回箭头说明返回哪个环节；纯分类与并列效果用分组框或列表。
- 主线粗一些，补充关系细一些或用虚线，并用短文字说明不同含义。不要让装饰箭头制造未经说明的关系。
- 默认每页有底部横向总结条，用黄色边框或标签写“核心结论 / 核心原则”，配一句回答教学目标的收束句，可补一两条条件或行动要点。结论短时缩小底栏；灯泡等提示图标按空间取舍。不能只有“很重要”“提效”等空泛口号。

## 布局选型

- 三栏：场景、机制、结果，或输入、处理、输出。先确定它们确实构成连续讲解。
- 左右对比：沿相同维度比较做法、适用条件或概念，不强行把中性差异归为对错。
- 流程：表达步骤、阶段、时序或有依据的因果；需要验收时写明分支条件与返工位置。
- 模块矩阵：各格共同解释一个分类或分工问题，使用一致的字段与抽象层级。格子不是独立海报，也不因排列就自动成为流程。
- 方法论页：围绕一个核心命题组织为什么、适用边界、机制或分工，底部提炼有条件、可操作的原则；放不下时按子问题拆页。

具体组件见 [板书组件库](components.md)，生成写法见 [提示词模板](prompt-recipes.md)。

## 插图与强调

- 简笔图标采用白色线稿，少量蓝、黄或红色细节。优先选与文字对应的具体物品，控制图标数量。
- 可用现代人物或通用机器人帮助读者代入，动作与本页内容有关。人物不用固定在中心；空间不足时去掉装饰人物。
- 装饰性对白和角落便签是可选项。若没有新增解释价值，就省略。
- 手绘风来自笔触和排版，不需要复制参考图的机器人造型、笔记本 Logo、完整文案或署名。

## 从参考图抽取与不抽取的内容

可复用：深色板面、粉笔字、蓝色分区、黄色重点、红色提醒；大标题、分区讲解、关系箭头、底部结论；少量说明性插图。补充规范增加了绿色状态、组件库、分类矩阵和方法论页面的细化规则。

只属于该示例：关于 AI 大任务的论点、“场景 → Agent → 后果”的具体内容、固定三种场景和五个后果、机器人对白、角落口号和 `01 / 03` 页码。新主题必须重新编排和核实。
