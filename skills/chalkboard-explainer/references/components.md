# 板书组件库

按内容选用，统一一页或一套课件的笔触、字号层级与颜色含义。完整教学单页默认包含标题、主体分区和底部总结；其余组件只在帮助理解时加入。

| 组件 | 默认构成 | 使用要点 |
| --- | --- | --- |
| 主标题 | 超大白色粉笔字、黄色下划线、短副标题 | 一句话说明本页问题，副标题限定对象或范围；角落装饰不能抢标题 |
| 章节标头 | 蓝色旗帜或横幅、模块名 | 同级模块使用相同样式；长名称改普通标题，不挤进窄旗帜 |
| 编号 | 粉笔圆圈、数字、短步骤名 | 用于有顺序的步骤；并列分类可用项目符号；默认同色，不随编号轮换风险色 |
| 内容框 | 白色或蓝色手绘框、名称、一至三行说明 | 框表示内容归组，同类卡片字段一致；不为每个词单独画框 |
| 箭头 | 手绘线、明确起终点、必要短标签 | 交代是顺序、输入输出、因果还是回退；不穿文字，不把并列事项串起来 |
| 简笔图标 | 白色主体线稿、少量强调色 | 时钟、文档、工具、路标等需对应本区含义；人物与机器人可省略 |
| 边注 | 一句小号手写说明、可选指向线 | 补充前提、例外或解释，不重复主标题；最多在确有空位处安排 |
| 总结条 | 横栏、黄色标签、一句核心原则 | 回答本页问题，可加一两条条件或行动；灯泡图标可选，不能替代总结文字 |
| 状态标记 | 状态词、对勾或警示形状 | 绿色通过，红色失败/风险；待执行用中性“待验收”，示例状态须标明是假设 |
| 页码 | 最小号粉笔字、实际页次 | 只给真实系列加页码；单张不凭空写成三页中的第一页 |

## 组合方式

- **解释问题**：主标题 + 场景组 + 机制框 + 并列影响或有依据的因果链 + 总结条。
- **教步骤**：主标题 + 编号流程 + 检查条件/回退线 + 边注 + 完成标准总结条。
- **讲边界与分工**：主标题 + 同一维度的对比或模块矩阵 + 条件说明 + 核心原则总结条。
- **制作系列**：统一标题、标头、状态标记和总结条的样式，每一页都有完整讲解，而非把一页剪成多块。

流程里的“通过 / 未通过”可作为条件标签，表示下一步怎么走；不要在讲未来工作法时给全部阶段打完成勾。若只是一般建议，用黄色强调建议内容即可。

## 组装后的阅读检查

第一眼能辨认主题，第二眼能找到模块和阅读方向，读到底部能复述一条具体结论。若去掉图标就读不懂，检查是否缺了必要文字；若去掉箭头结论仍一样，检查这些箭头是否只是装饰。
