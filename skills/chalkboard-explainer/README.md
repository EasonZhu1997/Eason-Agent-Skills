# 粉笔板书

完整风格名为“黑板手绘方法论信息图”，调用名仍是 `chalkboard-explainer`。把知识、流程和项目原理讲成一张黑板图：深色板面、白色粉笔正文、蓝色分区、黄色重点、少量红色提醒，需要表达通过或完成状态时加少量绿色。

本技能结合参考图片与《黑板手绘方法论信息图设计规范》整理。每页只讲一个核心问题，以“顶部主题—中部拆解—底部总结”组织内容，方便演示、扫读与复习。默认 16:9 独立单页，系列逐张交付。

支持问题解释、方法流程、概念对比、模块矩阵、方法论与适用边界，以及系列课件。主题不限定为 AI 或编程，用户指定的比例、形式和局部编辑范围优先。

## 怎么用

把整个 `chalkboard-explainer` 文件夹交给支持技能的 AI 助手，让它先读 [SKILL.md](SKILL.md)，再提供内容与使用场景。

```text
使用 $chalkboard-explainer，把这份讲稿整理成一张 16:9 粉笔板书。
对象是零基础读者，保留关键术语，用分区和箭头解释关系，底部给出一句结论。
```

```text
使用 $chalkboard-explainer，解释 Fork、Clone、Commit 和 Push 的区别。
分清原仓库、自己的 GitHub 副本和本地电脑，文字稍详细，但不要塞满黑板。
```

```text
使用 $chalkboard-explainer，把这些 AIUI 操作步骤画成板书。
顺序以我提供的资料为准，分别说明 AIUI Studio、真机验证和平台提审。
```

```text
使用 $chalkboard-explainer，先把 article.md 拆成两页课堂板书提纲和绘图提示词，暂时不要生图。
```

```text
使用 $chalkboard-explainer，按黑板手绘方法论信息图规范，讲清这套方法为什么有效、何时适用、何时可以简化。
一页一个核心问题，底部提炼核心原则；如果需要两页，分别生成完整单页。
```

## 包内资料

- [技能入口](SKILL.md)：内容整理、布局选择、生成与验收。
- [画风与排版](references/style-spec.md)：单页结构、板面、笔触、配色、字号和文案密度。
- [板书组件库](references/components.md)：标题、标头、编号、内容框、箭头、图标、边注、总结条、状态和页码。
- [布局与提示词](references/prompt-recipes.md)：六类布局、最短复用提示，含 GitHub、分工与方法论例子。
- `agents/openai.yaml`：显示名称与默认调用说明。
- [MIT 许可](LICENSE)：复制单个目录时一并保留。

成图需要宿主提供图片生成或编辑能力；未提供时可输出完整的布局与提示词。本包使用文字规范即可工作，不依赖原作者的本地图片。参考原图未作为素材再分发，使用者可自行提供有权使用的风格参考。

同一仓库的 [蓝墨纸绘](../blue-ink-paper-diagram/README.md) 适合暖白纸张上的黑笔与蓝墨手绘；本技能适合黑板粉笔讲解，两者可独立使用。
