## TXT / Markdown 平台适配

- CSDN 区分当前 Markdown 源码编辑器和富文本编辑器；其新 Markdown 图片流程默认只接受两个精确 CSDN 图床主机，额外主机须由本次原生上传核实并显式允许。
- Rokid 不预设图床；有图时须向回填和渲染两个步骤提供相同的已核实精确主机。单独图片段转成顶层 `<img width="100%">`，保持图文顺序。混排、链接包图或列表、引用、表格里的图片需先人工规范或原生插入，脚本不任意拆散结构。
- 两个平台的普通 TXT 默认走 `--literal-txt`，保留连续空格、制表符及首尾空行，不把 Markdown 示例解释为格式。用户确认 TXT 实际为 Markdown 后才切换解析路线。
- 新 Markdown 清单和原 Word 清单彼此独立；原图哈希、正文基线和逐次出现的图片映射均需通过检查后才能生成最终稿。

另外用独立合成素材按命令行完整执行了两个平台的“准备 → 模拟已核实地址回填 → 渲染”流程：两张图重复出现三次，逐项核对身份、次序、相邻图注和代码；HTML5 解析核对纯 TXT 空白；检查主机默认策略、精确主机及伪装子域拒绝，以及 Rokid 的五类非独立图片结构拒绝。此为离线前向验证，没有真实上传。
